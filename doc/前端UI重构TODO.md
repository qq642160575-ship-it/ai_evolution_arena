# 📝 前端重构任务清单 (To-Do List)

根据新的《前端UI重构文档》及极简中立指导原则，将原本的赛博朋克风完全剥离，并引入更好的交互逻辑。

## 阶段一：基础架构清理与样式剥离 🧼
- [ ] 1.1 **移除 Cyberpunk 样式资产**: 
      修改 `tailwind.config.js`，清理里面定义的 `cyber-pink`, `cyber-blue`, `cyber-dark`, `neon-gradient`, 以及各类 `text-shadow-neon` 插件。
- [ ] 1.2 **清理全局 CSS**: 
      重写 `index.css` 和 `App.css`，移除那些粗暴的背景渐变网格和呼吸发光特效，重置为极简中立的白/灰主题。
- [ ] 1.3 **精简字体**: 
      去除 `font-display` 大字体夸张映射，采用 Tailwind 默认无衬线字体集。

## 阶段二：布局与组件重构 🏗️
- [ ] 2.1 **重构 Header 与全局路由骨架**: 
      在 `App.tsx` 中把顶部的跑马灯闪耀标题改为左侧标准极简 Header（"AI Evolution Arena ⚖️"），右侧带“排行榜”切换，移除花哨动画。
- [ ] 2.2 **新增评价原则防干扰横幅 (Sticky Banner)**: 
      在主对阵框上方固定显示“⚖️ 评审原则：请忽略回复速度与排版...”的居中提示横条和当前轮数戳。
- [ ] 2.3 **引入 Markdown 渲染支持**: 
      安装 `react-markdown` 及相关插件（如 `remark-gfm`），让打字机流出的长文本能够渲染格式化的代码块和表格。确保两测渲染 CSS 一摸一样。

## 阶段三：对战区 (Arena) 逻辑与 UI 重设 ⚔️
- [ ] 3.1 **双轨卡片展示重构**:
      重写 Model A 与 Model B 的容器框，改用极简直角或微圆角底色卡片。顶栏带有简单的徽标文字 (“🤖 模型 A” / “🤖 模型 B”)。取消当前所有花哨的跳动 border 和阴影。
- [ ] 3.2 **底部悬浮操作台 (Sticky Action Dock)**:
      将输入框和投票键从原有的随意排列分离出来，固定在靠近底部的位置，且确保输入框状态跟随是否在生成而禁用。
- [ ] 3.3 **四大投票按钮的布局更新**:
      等待投票时，隐藏/虚化输入框，并排滑出四个等宽设计的投票按键：左优 (Indigo)、双优 (Gray)、双差 (Gray)、右优 (Teal)。移动端适配 (`md:hidden`) 更新文字为 “👍 选 A (上方)”等。

## 阶段四：“高光时刻”动效与收尾揭晓 🎁
- [ ] 4.1 **重构第 3 轮揭晓展示页面**: 
      移除目前的 “SYSTEM COMPROMISED” 红字赛博界面，改为模型 A 和 B 的名牌进行 3D 翻转 (`rotate-y-180`)，露出真实名称 (如 GPT 4o)。
- [ ] 4.2 **结果操作面板**: 
      翻转后，在页面中央或底部稳重地滑出“📊 查看战力榜”与“🔄 开启下一回合”按钮，风格统一。
- [ ] 4.3 **整体细节走查与调试**: 
      测试不同长度输入、Markdown 流式生成时候会不会抖动，确保用户始终能舒适聚焦于纯粹的 AI 回答内容的对比上。
