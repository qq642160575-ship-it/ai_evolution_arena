# 前端 UI 重构设计规范与架构设计 (本地化)

## 一、 全局 UI/UX 设计规范
鉴于当前项目为免登录、即开即用的“AI 进化竞技场”，目前的赛博朋克（Cyberpunk）高对比度风格可能会对用户的评价产生视觉疲劳或潜意识暗示。因此，我们需要向**“极简、中立、沉浸”**的方向重构。

- **色彩主题 (Color Palette):**
  - **背景与基础色:** `bg-gray-50` (亮色) 或 `bg-gray-900` (暗色)，文字采用 `text-gray-800` 和 `text-gray-200`。
  - **模型 A (Entity Alpha):** 靛蓝色 (Indigo-500) `#6366f1`。
  - **模型 B (Entity Beta):** 蓝绿色 (Teal-500) `#14b8a6`。
  - *移除原有的 `cyber-pink` 和 `cyber-blue` 等带有强烈情感倾向的颜色。*
- **排版 (Typography):**
  - 弃用之前强烈的 Cyberpunk 字体（如 `font-display tracking-[0.3em]` 等夸张样式）。
  - 使用系统的无衬线字体组合：`font-sans` (Inter, Roboto, 亦或是 PingFang SC)。
  - 设置大行高 `leading-relaxed` 或 `leading-loose` 以便阅读长篇回答。
  - 引入 `react-markdown` 渲染模型回答，确保左右两栏的渲染样式完全统一。
- **动效 (Animation):**
  - 去除所有的霓虹灯呼吸、闪烁 (`animate-pulse`) 和发光发热的 Hover 动效。
  - 保留并优化的动效：**SSE 打字机过渡**、**第 3 轮后的 3D 名牌翻转 (The Flip)**、平滑的悬浮操作台滑入。

## 二、 核心页面结构拆解

### 1. 顶部导航与提醒区 (Header & Sticky Banner)
- **Header:**
  - 极简居左：**AI Evolution Arena ⚖️**（深黑字，无渐变）。
  - 极简居右：Nexus/排行榜、Github 仓库链接等辅助按钮。
- **Banner (防干扰提示):**
  - 紧贴 Header 下侧的浅黄/浅灰背景条。
  - 居中文案：*“⚖️ 评审原则：请忽略回复速度与排版格式，仅针对回答内容的逻辑、准确性及有用性进行评价。”*
  - 右侧状态戳：`Round {turn} / 3`。

### 2. 双轨对话展示区 (Side-by-Side Area)
- **宽阔的主体与上下界限:**
  - 取消当前粗重的亮色边框。两栏均采用扁平化、略带圆角的卡片设计（`shadow-sm` 替代 `glass-panel`）。
- **用户 Prompt 的展示:**
  - 用户问题应以对话形式展示在页面上方，或者上方中心区域，气泡为浅灰 `bg-gray-100`。
- **模型回复容器:**
  - 左侧 (Model A)：顶部带有小标签 **“🤖 模型 A”**（文字颜色浅色或中性灰，Hover 也不变形）。
  - 右侧 (Model B)：顶部带有小标签 **“🤖 模型 B”**。
  - 两块区域均要引入 Markdown 渲染，支持代码高亮与格式化排版。

### 3. 悬浮操作台 (Sticky Action Dock)
将目前的表单输入改为真正的**底部固定或吸底 (Sticky)** 操作台。
- **状态一：等待输入 (Idle)**
  - 居中圆角多行文本框 (`textarea`)，自适应高度。
  - 右侧“发送”按钮，无赛博朋克发光，使用极简深色或浅色边框样式。
- **状态二：生成中 (Generating)**
  - 输入框变灰呈现 `disabled`。
  - 按钮呈现 Loading 态。
- **状态三：等待评价 (Voting Mode)**
  - 输入框淡出隐藏，或化作半透禁止状态。
  - 底部**横向平铺 4 个投票按钮**:
    1. `👈 左侧更优` (主按键，Indigo 边框或底色，不突兀)
    2. `🤝 两者双优` (次按键，Gray)
    3. `👎 两者双差` (次按键，Gray)
    4. `右侧更优 👉` (主按键，Teal 边框或底色，不突兀)

### 4. 高光时刻：开盲盒 (The Reveal)
- 评价第 3 轮完毕后：
  1. 底栏评价按钮立刻消失。
  2. 屏幕中央或上方标题处的 “模型 A” 与 “模型 B” 触发 3D 翻转 CSS 动画 (`rotate-y-180`)。
  3. 平滑展示真实模型 Logo 和名称（如 GPT-4o）。
  4. 底栏滑入进入下一局：`📊 查看战力榜` / `🔄 开启新对决`。

## 三、 移动端适配 (Mobile First)
- 在中等尺寸以下（`md` 断点），强制切换为**上下堆叠**：
- 模型 A 窗口在上，中间带有明显灰带与 `VS` 图标。
- 模型 B 窗口在下。
- 考虑到移动端用户浏览极长文本后无法找回 A 和 B，底部的四大投票按钮文字修改为：
  - `👍 选 A (上方)`
  - `🤝 平局`
  - `👎 都差`
  - `👍 选 B (下方)`
