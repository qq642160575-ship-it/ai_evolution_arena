这份 PRD 与架构设计逻辑严密、模块清晰，将 LangChain 作为底层编排层以支持并发流式输出和未来的 LangGraph 扩展，是一个极具前瞻性的决定。

为了让这个免登录、即开即用的“AI 进化竞技场”达到最佳的 ToC 用户体验，前端设计必须遵循**“极简、中立、沉浸”**的原则，避免 UI 元素对用户的评价产生任何心理暗示。

以下为你设计的用户友好型前端页面方案（基于 React/Vue 3 + Tailwind CSS 体系）：

---

## 一、 全局 UI/UX 设计规范 (Design System)

* **色彩主题 (Color Palette)：** * 采用极简的黑白灰（Neutral）为主色调，确保 Markdown 渲染（代码块、表格等）对比度极佳。
    * **模型 A / B 标识色：** 采用冷暖对比且无高低暗示的颜色，例如：Model A（靛蓝色 Indigo-500），Model B（蓝绿色 Teal-500）。
* **排版 (Typography)：** 优先使用系统默认无衬线字体（Inter / Roboto / PingFang SC），字号适中（16px），行高宽松（1.6），减轻长文本阅读疲劳。
* **动效 (Animation)：** 遵循“非必要不干扰”原则。仅在**SSE流式输出**（打字机平滑过渡）和**最终开盲盒**（3D 翻转）时使用明显动效。

---

## 二、 核心页面结构：盲测对战区 (Battle Arena)

页面采用经典的上下/左右分层布局，确保视线聚焦在对话内容本身。

### 1. 顶部导航与提醒区 (Header & Banner)
* **Logo 区：** 居中或居左显示 “AI Evolution Arena ⚔️”。右侧提供“排行榜 (Leaderboard)”入口。
* **防干扰横幅 (Sticky Banner)：** 紧贴导航栏下方，全宽浅黄色（Amber-50）背景，常驻提示：
    > *“⚖️ 评审原则：请忽略回复速度与排版格式，仅针对回答内容的逻辑、准确性及有用性进行评价。”*
* **进度指示器：** 在横幅右侧或中央显示当前轮次标签：`Round 1 / 3`。

### 2. 双轨对话展示区 (Side-by-Side Chat Board)
在 PC 端采用左右双栏布局（移动端为上下布局）。

* **用户提问 (User Prompt)：** 跨越两栏居中显示，或者在左右两栏同时展示，背景设为浅灰色（Gray-100），圆角气泡。
* **模型回复区 (Model Responses)：**
    * **左栏 (Model A)：** 顶部带有一个固定的小标签 “🤖 模型 A”。
    * **右栏 (Model B)：** 顶部带有小标签 “🤖 模型 B”。
    * **打字机体验：** 使用 Tailwind 的 `animate-pulse` 在光标处做闪烁效果。两栏的 Markdown 渲染样式必须**100% 保持一致**（使用相同的 CSS 类名）。

### 3. 悬浮操作台 (Sticky Action Dock)
固定在页面底部，包含输入框和评价按钮。状态机控制此处展示：

* **状态一：等待输入 (Idle)**
    * 显示宽大的输入框，带有多行支持（Textarea，随字数自适应高度）。
    * 右侧放置醒目的“发送”按钮（支持 `Cmd/Ctrl + Enter` 快捷键）。
* **状态二：生成中 (Generating)**
    * 输入框变为 `disabled` 状态，占位符变为“模型正在思考中...”。
    * 发送按钮变成 loading 状态（Spinner）。
* **状态三：等待评价 (Voting Mode)**
    * 输入框被**隐藏**或变为极低透明度的不可选状态。
    * 滑出 4 个评价按钮，横向排列：
        * `👈 左侧更优` (主按钮样式，Indigo)
        * `🤝 两者双优` (次按钮样式，Gray)
        * `👎 两者双差` (次按钮样式，Gray)
        * `右侧更优 👉` (主按钮样式，Teal)

---

## 三、 “高光时刻”：第 3 轮揭晓动效 (The Reveal)

为了强化“开盲盒”的爽感和北极星指标（让用户为了看结果而坚持投完 3 轮），第 3 轮投票后的交互至关重要：

1.  **评价提交：** 用户点击第 3 轮的评价按钮后。
2.  **屏息时刻 (0.5秒)：** 页面中央出现一个微小的聚光灯或心跳缩放动效，吸引注意力。
3.  **身份翻转 (The Flip)：** * 模型 A 和 模型 B 顶部的名称标签触发 3D 翻转动效 (`transform: rotateY(180deg)`)。
    * 翻转后，展示出真实的 Logo 和名称（例如：🌟 **GPT-4o** vs 🌟 **Claude 3.5 Sonnet**）。
4.  **操作台切换：** 底部的悬浮操作台不再显示输入框，而是滑出两个强引导按钮：
    * `📊 查看最新战力榜`
    * `🔄 开启下一局对决` (高亮主按钮)

---

## 四、 移动端适配策略 (Mobile First)

由于双栏在手机上极其拥挤，必须做特殊处理：

* **布局转换：** 由左右并排转为**上下堆叠**。
* **视觉隔离：** 模型 A 的回复和模型 B 的回复之间，使用一条带有明显 “VS” 徽章的粗分割线隔开。
* **评价操作前置：** 在移动端，如果回答很长，用户滑到底部可能忘了谁是谁。评价按钮应设计为：
    * `👍 选 A (上方)`
    * `🤝 平局`
    * `👎 都差`
    * `👍 选 B (下方)`
